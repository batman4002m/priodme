# پریود من 🌷

وب‌اپ موبایلی فرانت‌اند برای ثبت و پیگیری پریود، مناسب GitHub Pages.

## امکانات
- انتخاب دستی روز ۱ تا ۷ و نمایش راهنمای همان روز
- ثبت تاریخ شروع پریود و شمارش روزهای چرخه
- وارد کردن دستی تاریخ پریود بعدی
- یادآوری رسیدن تاریخ بعدی و سؤال «پریود شدی؟»
- اعلان مرورگر در صورت پشتیبانی
- تاریخ‌های چرخه به شکل کارت‌های مرتب و خوانا
- تنظیم مدت پریود و طول چرخه
- پاک کردن سوابق یا تمام داده‌ها
- صداهای کوتاه برای دکمه‌ها با Web Audio، بدون فایل خارجی
- مناسب GitHub Pages و موبایل
